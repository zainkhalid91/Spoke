05 · File drop — converting a video, then the result toast
While converting: the wheel stays where you dropped the file, the other slices grey out, and the hub shows a progress ring. Esc cancels and deletes the partial file.
You can click away; the job keeps running, and the tray icon shows a small progress dot.
Result toast (bottom-right): new file name, size before → after, Open / Show in folder. Never overwrites; saved as “name (Spoke).ext”.
