04 · File drop — format wheel (dragging photo.heic)
How it opens: while dragging a file, press the wheel shortcut, or drag into a hot corner. (Explorer right-click → Convert with Spoke… opens the same wheel.)
Each slice shows the estimated output size, computed by the worker from a quick sample encode before you drop.
The source format is greyed. HEIC appears only if the HEIF codec is installed.
Video gets its own wheel: MP4 · WEBM · MOV · MKV · GIF · MUTE · AUDIO ▸ (MP3/AAC/WAV/REPLACE).
